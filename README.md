# آکادمی هوش مصنوعی (AI Academy)

**وضعیت:** Milestone 1 + ممیزی کیفیت. هنوز هیچ قابلیت هوش مصنوعی فعال نیست و چیزی مستقر (deploy) نشده است.

## اجرای محلی (روی کامپیوتر شما)
۱. Node.js نسخه ۲۰.۱۹ یا بالاتر (ترجیحاً ۲۲) را از nodejs.org نصب کنید.
۲. در ترمینال:
```
cd frontend
npm install
npm run dev
```
۳. آدرس چاپ‌شده (مثلاً `http://localhost:5173`) را در مرورگر باز کنید.

## ساخت نسخه نهایی
```
npm run build
npm run preview
```

## مهم: فایل package-lock.json
پس از اولین `npm install` فایل `frontend/package-lock.json` ساخته می‌شود. **حتماً آن را هم commit کنید** تا نصب در گیت‌هاب دقیقاً همان نسخه‌ها را بگیرد.

## ساختار
- `frontend/` برنامه React (PWA، فارسی، راست‌به‌چپ)
- `worker/` بک‌اند Cloudflare Worker (فعلاً فقط `/api/health`)
- `env.example` نمونه تنظیمات (فقط مقدار نمونه؛ کلید واقعی هرگز در گیت‌هاب نگذارید)
- `SECURITY.md` قواعد امنیتی

## آماده است
رابط فارسی RTL، تم تیره/روشن، منوی دسکتاپ و موبایل (۵ بخش اصلی + «بیشتر»)، داشبورد پایه، آیکون‌های SVG، PWA با آیکون PNG، مسیریابی سازگار با GitHub Pages، اسکلت Worker امن.

## هنوز ساخته نشده
IndexedDB و دوره‌ها (۲)، AI و Worker کامل (۳)، تولید دوره و معلم (۴)، بازی‌ها و آزمون‌ها (۵)، تحلیل پیشرفت (۶)، استقرار و راهنمای کامل (۷).
